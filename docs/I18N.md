# I18N.md: หน้าเว็บหลายภาษา

ภาษา: ไทย (ต้นฉบับ) · English · 中文 · 日本語 · 한국어 · Français · Deutsch
ผู้ใช้เลือกที่ปุ่มลูกโลก: แถบด้านบน, เมนู "เพิ่มเติม" บนมือถือ, หน้าเข้าสู่ระบบ/สมัคร, หน้าแรก และหน้าผู้ปกครอง (จำไว้ในเครื่อง `kruscan.lang`)

## หลักการ

- **ข้อความไทยต้นฉบับคือ key** ไม่ต้องตั้งชื่อ key เอง: `t('บันทึกแล้ว')`
- คำแปลอยู่ที่ `frontend/src/i18n/locales/<ภาษา>.json` รูปแบบ `{ "ข้อความไทย": "คำแปล" }`
- ไม่มีคำแปล = แสดงภาษาไทยเดิม (ไม่พัง)
- ข้อความจาก server แปลให้เองที่ `services/api.js` (ดูหัวข้อ "ข้อความจาก server")
- เพิ่มข้อความใหม่ → รัน `node scripts/i18n-keys.js` เพื่อดูว่าภาษาไหนยังขาดคำแปล

## วิธีครอบข้อความ

```js
import { t } from '../../i18n';          // path ตามตำแหน่งไฟล์

<h1>{t('ห้องเรียน')}</h1>
<input placeholder={t('ค้นหาชื่อ')} aria-label={t('ค้นหา')} />
setError(t('บันทึกไม่สำเร็จ ลองใหม่อีกครั้ง'));
t('สร้างแล้ว {n} ห้อง', { n: ids.length })      // ตัวแปรใช้ {ชื่อ} ห้ามต่อ string
t('ลบ "{name}" ใช่ไหม?', { name: row.name })
```

กติกา:
1. **อาร์กิวเมนต์แรกต้องเป็นข้อความตายตัว** (string literal) เสมอ ห้าม `t(variable)` ห้าม template literal ที่มี `${}` ข้างใน — ยกเว้นค่าที่มาจากตารางคำคงที่ (ดูข้อ 2)
2. **ค่าคงที่ระดับโมดูล** (เช่น `const STATUS_LABEL = { DONE: 'เสร็จแล้ว' }`, รายการเมนู, ตัวเลือก) ให้คงเป็นภาษาไทยไว้ แล้วเรียก `t()` **ตอนแสดงผล**: `{t(STATUS_LABEL[s])}` · ห้ามเรียก `t()` ตอน import ไฟล์ เพราะจะไม่เปลี่ยนตามภาษา
   - ข้อยกเว้นเดียวที่ให้ส่งตัวแปรเข้า `t()`: เนื้อหาแบบประเมินสำเร็จรูปของบันทึกหลังแผนที่มาจาก server (ชื่อแบบ ชื่อระดับ คำถาม/ตัวเลือกระดับห้อง) ให้เรียก `t(value)` ตอนแสดงผล · ชื่อที่ครูตั้งเองไม่มีคำแปลก็แสดงตามเดิม · ห้ามแปลค่าที่อยู่ในช่องกรอก (input) หรือค่าที่ส่งกลับ API
3. ประโยคที่มีตัวเลข/ชื่อแทรก: ทำเป็นประโยคเดียวพร้อม `{ตัวแปร}` อย่าตัดเป็นท่อน ๆ (ลำดับคำแต่ละภาษาไม่เหมือนกัน)
4. ข้อความที่ปนตัวหนา/ลิงก์/ไอคอนกลางประโยค ใช้ `tx()` ให้ทั้งประโยคเป็นข้อความเดียว ห้ามตัดเป็น `t('ส่งครบ ')<b>…</b>t(' คน')`
   ```js
   import { tx } from '../../i18n';
   tx('ส่งครบ <b>{done}/{all}</b> คน', { done, all, b: (c) => <b className="…">{c}</b> })   // ฟังก์ชัน = แท็ก <b>…</b>
   tx('เลขที่ {no} {name} · ส่งแล้ว', { no, name: <b>{name}</b> })                          // element = วางแทน {name}
   tx('ยังไม่ส่ง<br/>สมุด', { br: () => <br /> })                                            // แท็กเดี่ยว <br/>
   ```
   ผู้แปลย้ายแท็กได้ตามไวยากรณ์ภาษานั้น · ชื่อแท็กในคำแปลต้องตรงกับต้นฉบับ (สคริปต์รวมคำแปลตรวจให้)

## พหูพจน์ (อังกฤษ ฝรั่งเศส เยอรมัน)

ต้นฉบับไทยไม่ต้องทำอะไร คำแปลเขียน `{ตัวแปร|เอกพจน์|พหูพจน์}` ได้ ระบบเลือกรูปตาม `Intl.PluralRules` ของภาษานั้น (ฝรั่งเศส 0 กับ 1 เป็นเอกพจน์)
`"ลบ {n} คน": "Delete {n} {n|student|students}"` → n=1 "Delete 1 student" · n=3 "Delete 3 students"

## ข้อความจาก server

- `services/api.js` แปลให้เอง: `error` ของคำตอบที่ผิดพลาด, `message` ชั้นบนสุด และ `reason` ของแต่ละรายการ (เช่นผลนำเข้า/ลบหลายรายการ)
- ข้อความที่แทรกค่า ให้เขียนใน backend เป็น template literal: `` `ไม่พบนักเรียนรหัส ${studentCode}` `` (ห้ามต่อ string ด้วย `+`)
  สคริปต์เก็บเป็น key `ไม่พบนักเรียนรหัส {studentCode}` แล้วหน้าเว็บจับรูปแบบด้วย `tMsg()` ตอนแสดง
- ค่าที่มาจาก server แต่ไม่ได้ผ่าน api.js (เช่นสถานะงานในหน้าผู้ปกครอง, ชื่อตัวชี้วัดของแบบสำเร็จรูป) ใช้ `tMsg(value)` ตอนแสดงผล

## ห้ามครอบ (คงภาษาไทย)

- ค่าที่โค้ดเอาไปเทียบ, ค่าที่ส่งไป API, key ของ localStorage, regex, path
- หัวคอลัมน์ไฟล์นำเข้าและคำที่ parser ใช้จับคอลัมน์
- **เนื้อหาเอกสารราชการ**: ตัวอย่างกระดาษ/ไฟล์ Word บันทึกหลังแผน (`PaperPreview.js`) และข้อความในไฟล์ Excel/Word ที่ส่งออก
- ข้อความทวงงานที่ครูคัดลอกไปส่งผู้ปกครอง (`reminderText.js`)
- ชื่อเดือนไทยและวันที่แบบ พ.ศ. (`lessonLogCore.js`, `ThaiDatePicker.js`)
- ชื่อคน ชื่อห้อง ชื่อวิชา ที่มาจากข้อมูล
- console.log / ข้อความ error ภายในที่ผู้ใช้ไม่เห็น / คอมเมนต์
