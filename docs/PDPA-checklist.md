# PDPA — สิ่งที่เจ้าของระบบ/โรงเรียนต้องตัดสินใจ

หน้าสาธารณะ `/privacy` (`frontend/src/pages/legal/PrivacyNotice.js`) เขียนตามพฤติกรรมของโค้ดจริง จุดที่ยังว่างเป็นกรอบเหลือง "โรงเรียนต้องกรอก" ต้องทำให้ครบก่อนแจกลิงก์ให้ผู้ปกครอง

## 1. ฐานทางกฎหมาย และความยินยอมจากผู้ปกครอง
- [ ] เลือกฐานทางกฎหมาย: ภารกิจจัดการศึกษา (ประโยชน์สาธารณะ) หรือความยินยอม
- [ ] นักเรียนเป็นผู้เยาว์ — ถ้าใช้ความยินยอม ต้องได้จากผู้ปกครอง ร่างหนังสือแจ้ง/ยินยอมและวิธีเก็บหลักฐาน (ระบบยังไม่มีตารางบันทึกการยินยอม)
- [ ] แจ้งผู้ปกครองก่อนแจกลิงก์ผู้ปกครอง (ลิงก์ใครถือก็เปิดได้)

## 2. ผู้ช่วย AI และข้อตกลงกับผู้ให้บริการ
- [ ] ตัดสินใจ: เปิดใช้ AI หรือไม่ (ไม่ตั้งคีย์ = ไม่มีข้อมูลออกนอก)
- [ ] ถ้าเปิด: เลือกผู้ให้บริการ (Anthropic / Gemini / OpenAI) และทำข้อตกลงประมวลผลข้อมูล (DPA) ตรวจเรื่องส่งข้อมูลไปต่างประเทศ และปิดการนำข้อมูลไปฝึกโมเดล
- [ ] ตัดสินใจ: ปกปิดชื่อนักเรียน (pseudonymise) ก่อนส่ง AI หรือไม่ — ตอนนี้ส่งชื่อจริง (มีหมายเหตุใน `backend/controllers/aiController.js`)
- [ ] อัปเดตชื่อผู้ให้บริการ/DPA ในหัวข้อ 3 ของหน้า `/privacy`

## 3. ระยะเวลาเก็บและการลบ
- [ ] กำหนดระยะเก็บ (เช่น กี่ปีหลังจบ/ย้ายออก) — ระบบไม่ลบอัตโนมัติ และ "ไม่ใช้งาน" ไม่ใช่การลบ
- [ ] กำหนดผู้รับผิดชอบลบ/ไม่ระบุตัวตนข้อมูลเมื่อครบกำหนด และขั้นตอนตอบคำขอลบ
- [ ] ตั้งค่า `PARENT_LINK_DAYS` (ค่าเริ่มต้น 120 วัน) และ `PARENT_LINK_SECRET` แยกจาก `JWT_SECRET` ใน production
- [ ] ตัดสินใจขั้นตอนเมื่อลิงก์ผู้ปกครองหลุด (ตอนนี้ไม่มีปุ่มยกเลิกรายคน ต้องเปลี่ยน secret ซึ่งยกเลิกทุกลิงก์)

## 4. DPO และช่องทางใช้สิทธิ์
- [ ] ระบุผู้ควบคุมข้อมูล (ชื่อโรงเรียน) และ DPO/ผู้รับผิดชอบ
- [ ] ช่องทางติดต่อ (อีเมล/โทร) และระยะเวลาตอบ (ปกติไม่เกิน 30 วัน)
- [ ] ขั้นตอนแจ้งเหตุข้อมูลรั่ว (แจ้ง สคส. ภายใน 72 ชั่วโมงเมื่อมีความเสี่ยง)
- [ ] กรอกข้อมูลข้างต้นในหัวข้อ 7 ของหน้า `/privacy`

## 5. ความปลอดภัย (ข้อสังเกตจากโค้ด ควรตัดสินใจ)
- [ ] นักเรียนล็อกอินด้วย รหัสนักเรียน เป็นทั้งชื่อผู้ใช้และรหัสผ่าน (เดาง่าย) — พิจารณาเปลี่ยนวิธี หรือยอมรับความเสี่ยงเพราะนักเรียนเห็นเฉพาะข้อมูลตนเอง
- [ ] ครูทุกคนดูข้อมูลนักเรียนทุกห้องได้ในหน้าติดตามงาน (จำกัดเฉพาะการแก้ไข) — ตัดสินใจว่ายอมรับหรือจะจำกัดตามห้องที่สอน
- [ ] เปิด HTTPS และตั้ง `ADMIN_PASSWORD_HASH`
- [ ] ผูกลิงก์ `/privacy` ในหน้าเข้าสู่ระบบและท้ายหน้าลิงก์ผู้ปกครอง
